# HNG Profile Card Project

This is a simple profile card component built with HTML and CSS, created as part of the HNG internship.

## Features

* Responsive profile card layout
* Links to social media profiles
* Displays current time, updating every second
* Uses `data-testid` attributes for easy testing.

## How to Run Locally

1.  **Clone the repository:**
    ```sh
    git clone (https://github.com/Lolu00/hng-profile-card)..git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd [hng-profile-card]
    ```
3.  **Open the file:**
    Open the `https://github.com/Lolu00/hng-profile-card/blob/main/index.html` file directly in your web browser.
